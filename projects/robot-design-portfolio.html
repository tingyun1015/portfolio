Overview

The portfolio showcases research, design, and prototyping work from the "Designing Human-Robot Interaction and Human-AI Interaction" course at National Chengchi University (NCCU). It features three core projects: a dancing robot, an interactive chatbot guide, and a concert robot.

Portfolio Site

https://tingyun1015.github.io/Robot_Design_Portfolio/index.html

While the coursework was a team effort, I designed and built this portfolio website myself, using Claude Design for visual exploration and Claude Code for the initial build, followed by hands-on refinement. Here is how the site came together.

Co-working with Claude Design

I started by sharing our project context, content structure, and visual goals with Claude Design to explore layout ideas. It proposed four different visual directions:

I chose the top-right editorial layout. Unlike typical dark sci-fi portfolios, our work features warm, playful designs with soft, fluffy materials. The editorial style felt much cleaner and naturally highlighted our research and physical prototypes.

After settling on the direction, I refined the interaction details with Claude Design. The initial mockup showed floating image previews on hover, but I found them distracting. I prompted Claude Design to remove the hover preview and focus purely on clean project titles instead:

Implementing with Claude Code & Manual Fine-Tuning

Once the visual direction was set, I used Claude Code to generate the base HTML and CSS structure. From there, I adjusted the layout and page templates so each project could present its research story clearly.
